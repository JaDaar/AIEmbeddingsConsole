C# is a modern, object-oriented programming language developed by Microsoft. It runs on .NET and is used to build desktop, web, cloud, mobile and game applications.

An embedding is a list of numbers (a vector) that represents the meaning of a piece of text. Texts with similar meanings produce vectors that point in similar directions, so cosine similarity can be used to find related content even when the exact words differ.

Async and await in C# let a program start a long-running operation, such as a network request, without blocking the calling thread. The compiler rewrites async methods into state machines behind the scenes.
